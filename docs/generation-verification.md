
## Reproducible release report and M1 boundary

`npm run setup:generation-protocol` checks the existing pinned Quint 0.33.0 / Apalache 0.62.1 / bundled TLC distribution. `npm run verify:generation-protocol -- --release` creates a fresh directory under `verification-evidence/generation-protocol/`; `GENERATION_EVIDENCE_DIR` can select another output root. The fast profile always runs all eight complete TLC domains, their independently bounded Apalache checks, both broad and refined native witness/simulation corpora, four model mutants, 57 real refined replays, four actual implementation controls, and the 35 real boundary regressions. Broad simulation is model-only evidence, never silently substituted for an unreplayable production trace.

The original per-check budgets remain TLC 300 seconds and fast Apalache 240 seconds; selected depths remain 8 for single/budget domains and 5 for the concurrent domains. The explicitly selected deep profile retains its own depth 12/8 and 600-second BMC bounds. The whole fast/deep worker deadlines are 35/70 minutes, fixed before release runs using the existing full-domain cost measurements. A separate process-group supervisor gives the worker 15 seconds to stop and then uses bounded termination; it does not turn an incomplete model into a pass. CI reserves 45 minutes for fast setup, checks and evidence upload. Deep is not run by the fast CI job and is never implied by its success.

`npm run verify:generation-protocol:report -- RUN_DIRECTORY --release` recomputes acceptance from the exact current source/runtime/lock/model hashes, explicit property roster, commands, exits, tool versions, native ITF files and raw SQLite/callback/process observations. Recorded `ok` flags and first-difference labels are not sufficient. All start/end times, command ports, check ordering, supervisor termination, trace origin hashes and normal/mutated comparisons must agree. The transaction mutant is explicitly a **direct old-context transaction call**, not a claim that ordinary workflow abort allowed that continuation through.

`npm run verify:m1:report -- --relation RELATION_RUN --knowledge KNOWLEDGE_RUN --process PROCESS_RUN --generation GENERATION_RUN --release` invokes the existing KEJ-63/64/65 gates and this KEJ-66 gate against one current checkout, then emits the exact AC-P01–P12 matrix. A missing profile is `not_run`; another source is `stale`; a timeout, changed artifact or failed required check is `incomplete`. Prior PRs having passed does not produce a current M1 pass. The CI aggregation job downloads the four artifacts for the same synthetic source SHA and revalidates them after rebuilding that checkout. Its conclusion covers the declared finite profiles, not unbounded behavior, arbitrary supplier quality, or deep exploration.
